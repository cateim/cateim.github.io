# cateim.github.io

The root of <https://cateim.github.io/>: a one-page list of projects, and the
place where Google Search Console checks that `cateim.github.io` belongs to
this account. That check is what lets Google Cloud projects use
`cateim.github.io` as an authorized domain, for example DriveSync's sign-in
screen, whose pages live at <https://cateim.github.io/drivesync/>.

Each project page is published by its own repository, under its own path.
This one publishes only `site/`.
